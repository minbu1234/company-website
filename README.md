# 株式会社M&Hコンサルティング 公式ホームページ

HTMLとCSSだけで作った、シンプルなホームページです。
WordPressなどのソフトは使っていないので、ファイルを開いて文章を書き換えるだけで直せます。

## 1. ファイルの構成

```
company-website/
├── index.html      トップページ
├── company.html    会社概要
├── services.html   サービス紹介
├── pricing.html    料金
├── contact.html    お問い合わせ
├── css/
│   └── style.css   デザイン（色・文字の大きさ・配置）。5ページ共通
├── images/         画像を入れるフォルダ（今は仮の画像が入っています）
│   ├── hero.svg      トップのメイン画像
│   ├── services.svg  サービス紹介の画像
│   ├── ceo.svg       代表者の写真
│   └── map.svg       地図
└── README.md       この説明書
```

- **文章を直すとき** → `○○.html` を開きます。
- **色やデザインを変えるとき** → `css/style.css` を開きます。

## 2. 自分のパソコンで表示を確認する方法

### ① ファイルをパソコンに保存する

1. GitHubでこのリポジトリのページを開きます。
2. 画面左上のブランチ名（`main` などと書かれたボタン）をクリックし、`claude/sleepy-mayer-k451s4` を選びます。
   - サイトが `main` ブランチに入ったあとは、この手順は不要です。
3. 緑色の **「Code」** ボタン → **「Download ZIP」** をクリックします。
4. ダウンロードしたZIPファイルを右クリック → **「すべて展開」**（Macはダブルクリック）で展開します。

### ② ブラウザで開く

1. 展開したフォルダの中の **`index.html`** をダブルクリックします。
2. ChromeやEdgeなどのブラウザでトップページが開きます。メニューから他のページにも移動できます。

> インターネットにつながっていなくても表示できます。

### ③ スマホでの見え方を確認する（Chrome・Edge）

1. ページを開いた状態で、キーボードの **F12** を押します（Macは `Command + Option + I`）。
2. 開いた画面の左上にある **スマホとタブレットの形のアイコン** をクリックします。
3. 画面上部の機種名（「Dimensions」など）で **iPhone** などを選ぶと、スマホの幅で表示されます。
4. 元に戻すときは、もう一度 **F12** を押します。

## 3. 文章を直す方法

### 使うソフト

- **おすすめ：Visual Studio Code（無料）**
  「VS Code」で検索してインストールし、`.html` ファイルを右クリック →「プログラムから開く」→「Visual Studio Code」で開きます。
- **Windowsのメモ帳でも直せます。**
  保存するときに、文字コードが **「UTF-8」** になっていることを確認してください（文字化けを防ぐため）。

### 手順

1. 直したいページの `.html` ファイルを、上のソフトで開きます。
2. **`Ctrl + F`**（Macは `Command + F`）で **`【要入力`** を検索します。
3. `【要入力：○○】` の部分を消して、正しい文章を書きます。
   ```html
   変更前： <h1 class="hero-title">【要入力：キャッチコピー】</h1>
   変更後： <h1 class="hero-title">（ここに、考えたキャッチコピーを書きます）</h1>
   ```
4. **上書き保存**（`Ctrl + S`）します。
5. ブラウザで **F5**（再読み込み）を押すと、変更が反映されます。

### 直すときの注意

- `<` と `>` で囲まれた部分（**タグ**）は消さないでください。直すのは、タグとタグの**間の文字**だけです。
- `<!-- ▼○○ -->` は**メモ**です。画面には表示されません。そのまま残しても、消しても大丈夫です。
- 社名の「&」は、HTMLの中では **`&amp;`** と書いています（`M&amp;H` → 画面では「M&H」）。
- 段落を増やすときは、`<p>文章</p>` を1行追加します。
- 改行したいところには `<br>` を入れます。

### 全ページ共通の部分（5ファイルすべて直す必要があります）

次の部分は5つの `.html` ファイルのそれぞれに書いてあります。直すときは **5ファイルとも** 同じように直してください。

| 部分 | ファイル内の目印 |
|---|---|
| ヘッダー（社名とメニュー） | `<!-- ===== ヘッダー` |
| フッター（社名・郵便番号・住所・メニュー） | `<!-- ===== フッター` |

VS Codeを使う場合は、**`Ctrl + Shift + H`**（全ファイルで置換）を使うと、5ファイルをまとめて書き換えられます。

### 電話番号・メールアドレスの直し方

電話番号とメールアドレスは、**トップ（index.html）・会社概要（company.html）・お問い合わせ（contact.html）** の3ページにあります。

トップとお問い合わせでは、スマホで押すと電話がかかる・メールソフトが開くリンクになっています。**2か所**を直してください。

```html
変更前： <a href="tel:【要入力】">【要入力：電話番号】</a>
変更後： <a href="tel:0312345678">03-1234-5678</a>
```
- `tel:` のあとは **ハイフンなしの数字** にします。
- 画面に表示される部分は、ハイフンありで大丈夫です。

```html
変更前： <a href="mailto:【要入力】">【要入力：メールアドレス】</a>
変更後： <a href="mailto:info@example.co.jp">info@example.co.jp</a>
```
※上の電話番号とメールアドレスは書き方の例です。

## 4. 【要入力】の場所の一覧

| ページ | 【要入力】の内容 |
|---|---|
| **全ページのフッター** | 郵便番号 |
| **トップ（index.html）** | 検索結果に表示される説明文（ファイル上部の `description`）、キャッチコピー、キャッチコピーの下の文章、選ばれる理由（見出しと本文×3）、会社情報の郵便番号、電話番号、受付時間、メールアドレス |
| **会社概要（company.html）** | 代表挨拶の本文、郵便番号（表とアクセスの2か所）、電話番号、メールアドレス、最寄り駅 |
| **サービス紹介（services.html）** | サービス全体の紹介文、各業務の説明（6つ）、ご依頼の流れの説明（5つ） |
| **料金（pricing.html）** | お支払い方法、契約期間などの条件 |

> サービス紹介の「ご依頼の流れ」の各段階の名前（お問い合わせ → ヒアリング → …）は仮のものです。実際の流れに合わせて直してください。

## 5. 料金を直す方法

料金ページ（`pricing.html`）の金額は、**同業他社の相場を参考にした仮の金額** です。公開する前に必ず直してください。

1. `pricing.html` を開き、金額を書き換えます。
2. 金額の横の **`<span class="temp">※仮</span>`** をまるごと消します（画面では赤い「※仮」の部分です）。
3. ページ上部の黄色い注意枠を消します。`<!-- ▼▼ 仮の金額のお知らせ` から `<!-- ▲▲ 仮の金額のお知らせ ここまで ▲▲ -->` までを、まるごと削除してください。
4. 基本料金や1名あたりの料金を変えた場合は、**「人数別の月額の例」** も計算し直します。
   - 計算方法：基本料金 ＋（人数 − 5）× 1名あたりの料金
5. **トップページ（index.html）の「料金の目安」** にも、月額と初期費用が書いてあります。同じ金額に直し、「※仮」も消してください。

参考にした相場（2026年10月時点で調べたもの）：

| 項目 | 相場 |
|---|---|
| 月額 | 「基本料金＋1名あたり料金」の形が多い。5名まで1万〜3万円、1名追加800〜1,700円程度 |
| 初期費用 | 0〜10万円程度 |
| 賞与計算 | 基本1万〜1.5万円＋1名500〜1,700円、または月額料金の0.5〜1ヶ月分 |
| オプション | 明細の印刷・振込データ作成・住民税の更新は別料金が一般的 |

> **ご注意**：社会保険の手続き（社会保険労務士の業務）と年末調整（税理士の業務）は、資格がないと有料で引き受けられない業務とされています。料金表に追加する場合は、社労士・税理士と提携してからにしてください。

## 6. 画像を差し替える方法

今は、灰色の「仮の画像」が入っています。

### 手順

1. 使いたい写真を用意します。
   - ファイル名は **半角の英数字** にしてください（例：`hero.jpg`）。日本語のファイル名は避けます。
   - 写真は `.jpg`、ロゴやイラストは `.png` がおすすめです。
2. 写真を **`images` フォルダ** に入れます。
3. `.html` ファイルの `<img src="images/○○.svg"` の部分を、新しいファイル名に書き換えます。
   ```html
   変更前： <img src="images/hero.svg" alt="メイン画像" width="1200" height="800">
   変更後： <img src="images/hero.jpg" alt="オフィスの様子" width="1200" height="800">
   ```
   - `alt="…"` は、画像が表示されないときや、目の不自由な方の読み上げで使われる**画像の説明**です。写真の内容に合わせて書き換えてください。
   - `width` と `height` は写真の縦横の比率に合わせると、表示がよりなめらかになります（そのままでも表示できます）。
4. 保存して、ブラウザで再読み込み（F5）します。
5. 使わなくなった仮の画像（`.svg`）は、`images` フォルダから削除してかまいません。

### 画像の場所とおすすめの大きさ

| 画像 | ファイル | 使っているページ | おすすめの大きさ（横×縦） |
|---|---|---|---|
| メイン画像 | `images/hero.svg` | トップ | 1200 × 800 |
| サービス紹介の画像 | `images/services.svg` | サービス紹介 | 1200 × 600 |
| 代表者の写真 | `images/ceo.svg` | 会社概要 | 600 × 600（正方形） |
| 地図 | `images/map.svg` | 会社概要 | 1200 × 600 |

- 写真が大きすぎると表示が遅くなります。1枚 **500KB以下** を目安にしてください。
- 他のサイトの写真は使わないでください（著作権の問題があります）。自社で撮影した写真か、利用が許可された素材を使ってください。

### 地図をGoogleマップに差し替える場合（任意）

1. Googleマップで会社の住所を検索し、**「共有」→「地図を埋め込む」→「HTMLをコピー」** を押します。
2. `company.html` の `<img src="images/map.svg" … >` の1行を消して、コピーしたもの（`<iframe …></iframe>`）を貼り付けます。
3. 貼り付けた `<iframe` の中の `width="600"` を `width="100%"` に書き換えると、スマホでもはみ出しません。

## 7. 色を変える方法

`css/style.css` の最初のほうにある **「色・文字・幅の設定」** を書き換えると、サイト全体の色がまとめて変わります。

```css
:root {
  --color-main: #1e3a5f;        /* メインの色（濃い紺） */
  --color-main-dark: #142a46;   /* メインの色の濃いめ */
  --color-main-light: #e8eef5;  /* メインの色の薄いめ */
  ...
}
```

- `#1e3a5f` のような記号は、色を表す番号（カラーコード）です。
- 「カラーコード 一覧」などで検索すると、好きな色の番号を調べられます。

## 8. 項目を増やす・消す方法

### 会社概要の表の行

`<tr>` から `</tr>` までが1行です。
- **消すとき**：まとめて削除します。
- **増やすとき**：1行分をコピーして貼り付け、中身を書き換えます。

```html
<tr>
  <th>項目名</th>
  <td>内容</td>
</tr>
```

### サービスのカード

`<div class="card">` から、対応する `</div>` までが1枚です。コピーして増やしたり、削除したりできます。

### ご依頼の流れ

`<li>` から `</li>` までが1段階です。番号（1, 2, 3…）は自動で付きます。
