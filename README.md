## 1. ファイルの構成

```
company-website/
├── index.html      トップページ
├── company.html    会社概要
├── services.html   サービス紹介
├── pricing.html    料金
├── css/
│   └── style.css   デザイン（色・文字の大きさ・配置）。4ページ共通
├── images/         画像を入れるフォルダ
│   └── services.svg  サービス紹介の画像（今は仮の画像です）
└── README.md       この説明書
```

- **文章を直すとき** → `○○.html` を開きます。
- **色やデザインを変えるとき** → `css/style.css` を開きます。

## 2. 自分のパソコンで表示を確認する方法

### ① ファイルをパソコンに保存する

1. GitHubでこのリポジトリのページを開きます。
2. 画面左上のブランチ名（`main` などと書かれたボタン）をクリックし、`claude/sleepy-mayer-k451s4` を選びます。
   - サイトが `main` ブランチに入ったあとは、この手順は不要です。
3. 緑色の **「Code」** ボタン → **「Download ZIP」** をクリックします。
4. ダウンロードしたZIPファイルを右クリック → **「すべて展開」**（Macはダブルクリック）で展開します。

> ブラウザの自動翻訳がオンになっていると、GitHubの表示が変わります。「main」は **「主要」**、「Code」は **「コード」** と表示されます。ファイル名やフォルダ名も日本語で表示されることがありますが、本当の名前は変わっていません。

### ② ブラウザで開く

1. 展開したフォルダの中の **`index.html`** をダブルクリックします。
2. ChromeやEdgeなどのブラウザでトップページが開きます。メニューから他のページにも移動できます。

> インターネットにつながっていなくても表示できます。

### ③ スマホでの見え方を確認する（Chrome・Edge）

1. ページを開いた状態で、キーボードの **F12** を押します（Macは `Command + Option + I`）。
2. 開いた画面の左上にある **スマホとタブレットの形のアイコン** をクリックします。
3. 画面上部の機種名（「Dimensions」など）で **iPhone** などを選ぶと、スマホの幅で表示されます。
4. 元に戻すときは、もう一度 **F12** を押します。

## 3. 文章を直す方法

### 使うソフト

- **おすすめ：Visual Studio Code（無料）**
  「VS Code」で検索してインストールし、`.html` ファイルを右クリック →「プログラムから開く」→「Visual Studio Code」で開きます。
- **Windowsのメモ帳でも直せます。**
  保存するときに、文字コードが **「UTF-8」** になっていることを確認してください（文字化けを防ぐため）。

### 手順

1. 直したいページの `.html` ファイルを、上のソフトで開きます。
2. **`Ctrl + F`**（Macは `Command + F`）で、直したい文章や **`【要入力`** を検索します。
3. 文章を書き換えます。
   ```html
   変更前： <p>【要入力】</p>
   変更後： <p>（ここに、答えの文章を書きます）</p>
   ```
4. **上書き保存**（`Ctrl + S`）します。
5. ブラウザで **F5**（再読み込み）を押すと、変更が反映されます。

### 直すときの注意

- `<` と `>` で囲まれた部分（**タグ**）は消さないでください。直すのは、タグとタグの**間の文字**だけです。
- `<!-- ▼○○ -->` は**メモ**です。画面には表示されません。そのまま残しても、消しても大丈夫です。
- 社名の「&」は、HTMLの中では **`&amp;`** と書いています（`M&amp;H` → 画面では「M&H」）。
- 段落を増やすときは、`<p>文章</p>` を1行追加します。
- 改行したいところには `<br>` を入れます。

### 全ページ共通の部分（4ファイルすべて直す必要があります）

次の部分は4つの `.html` ファイルのそれぞれに書いてあります。直すときは **4ファイルとも** 同じように直してください。

| 部分 | ファイル内の目印 |
|---|---|
| ヘッダー（社名とメニュー） | `<!-- ===== ヘッダー` |
| フッター（社名・住所・メニュー） | `<!-- ===== フッター` |

VS Codeを使う場合は、**`Ctrl + Shift + H`**（全ファイルで置換）を使うと、4ファイルをまとめて書き換えられます。

## 5. 料金を直す方法

料金は `pricing.html` に書いてあります。給与計算代行とコンサルティングの表の金額を、そのまま書き換えてください。

金額のあとのかっこ内は、税込の金額（税別の金額 × 1.1）です。税別の金額を変えたときは、**税込の金額も一緒に直してください**。

```html
<td>10,000円<span class="tax-in">（税込11,000円）</span></td>
```

給与計算の月額料金は、**10人ごとの区分**（10人まで・11〜20人・21〜30人…）の表になっています。区分を増やすときは、表の行（`<tr>`〜`</tr>`）をコピーして書き換えてください。

月額料金（10人までの金額）や初期費用を変えたときは、**トップページ（index.html）の「料金の目安」** も同じ金額に直してください。

コンサルティングの料金を決めるときに参考にした相場（2026年10月時点で調べたもの）：

| 項目 | 相場 |
|---|---|
| スポット相談 | 1時間あたり5,000円〜10万円と幅が広い |
| 経営診断 | 1日（5時間）10万円という基準あり（中小企業診断協会）。報告書の作成は別料金のことが多い |
| 顧問契約 | 月額10万円という基準あり（中小企業診断協会）。一般的なコンサル会社では月額20万〜50万円程度 |
| 事業承継計画の策定 | 一式50万〜300万円程度 |

> **ご注意**：社会保険の手続き（社会保険労務士の業務）、年末調整・税務相談（税理士の業務）、契約書の作成（弁護士の業務）は、資格がないと有料で引き受けられない業務とされています。料金表やサービスに追加する場合は、専門家と提携してからにしてください。

## 6. 画像を差し替える方法

今は、サービス紹介ページに灰色の「仮の画像」（`images/services.svg`）が入っています。

### 手順

1. 使いたい写真を用意します。
   - おすすめの大きさは **横1200 × 縦600** です。
   - ファイル名は **半角の英数字** にしてください（例：`services.jpg`）。日本語のファイル名は避けます。
   - 写真は `.jpg`、ロゴやイラストは `.png` がおすすめです。
2. 写真を **`images` フォルダ** に入れます。
3. `services.html` の `<img src="images/services.svg"` の部分を、新しいファイル名に書き換えます。
   ```html
   変更前： <img src="images/services.svg" alt="サービス紹介の画像" width="1200" height="600">
   変更後： <img src="images/services.jpg" alt="打合せの様子" width="1200" height="600">
   ```
   - `alt="…"` は、画像が表示されないときや、目の不自由な方の読み上げで使われる**画像の説明**です。写真の内容に合わせて書き換えてください。
4. 保存して、ブラウザで再読み込み（F5）します。
5. 使わなくなった `images/services.svg` は削除してかまいません。

### 画像を使わない場合

`services.html` の `<img src="images/services.svg" … >` の1行を消すと、画像がなくなり、文章だけが表示されます。

### 注意

- 写真が大きすぎると表示が遅くなります。1枚 **500KB以下** を目安にしてください。
- 他のサイトの写真は使わないでください（著作権の問題があります）。自社で撮影した写真か、利用が許可された素材を使ってください。

## 7. 色を変える方法

`css/style.css` の最初のほうにある **「色・文字・幅の設定」** を書き換えると、サイト全体の色がまとめて変わります。

```css
:root {
  --color-main: #1e3a5f;        /* メインの色（濃い紺） */
  --color-main-dark: #142a46;   /* メインの色の濃いめ */
  --color-main-light: #e8eef5;  /* メインの色の薄いめ */
  ...
}
```

- `#1e3a5f` のような記号は、色を表す番号（カラーコード）です。
- 「カラーコード 一覧」などで検索すると、好きな色の番号を調べられます。

## 8. 項目を増やす・消す方法

### 表の行（会社概要・料金・対応範囲）

`<tr>` から `</tr>` までが1行です。
- **消すとき**：まとめて削除します。
- **増やすとき**：1行分をコピーして貼り付け、中身を書き換えます。

```html
<tr>
  <th>項目名</th>
  <td>内容</td>
</tr>
```

### サービスのカード

`<div class="card">` から、対応する `</div>` までが1枚です。コピーして増やしたり、削除したりできます。

### こんなお悩み

`<li>` から `</li>` までが1行です。チェックマークは自動で付きます。

### ご依頼の流れ

`<li>` から `</li>` までが1段階です。番号（1, 2, 3…）は自動で付きます。
